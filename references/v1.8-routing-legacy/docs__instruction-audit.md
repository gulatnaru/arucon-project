# 지침 감사와 이동 기록

감사 대상: 제공된 v1.5 문서 묶음의 루트 AGENTS, docs/AGENTS, 단계별 프롬프트와 인계문. 사용자 실제 전역 AGENTS·저장소 추가 스킬·Git blame은 접근하지 않았으므로 감사하지 않았다. 과거 특정 모델의 실수를 추정해 안전 규칙을 삭제하지 않았다.

| 기존 문구/문제 | 처리 | 위치/근거 |
|---|---|---|
| 루트 AGENTS에서 docs 지침·결정·프롬프트를 모두 먼저 읽기 | 문서 위치 안내 + 관련 FR/DEC 읽기 | 새 루트 AGENTS, agent-workflow |
| docs/AGENTS를 루트로 옮기라는 경로 혼란 | 루트 공통, docs 보충으로 명확화 | 두 AGENTS |
| SRS 전체 먼저 읽기 | 전체 감사·아키텍처에만 전면 읽기, 나머지 관련 절 | 루트 AGENTS, 단계 프롬프트 |
| 공통 헤더를 작업마다 복사 | 이번 결과·제약·검증·멈출 지점만 작성 | task-brief |
| 한 세션 한 단계의 일률적 제한 | 단계 의존성은 유지, 배정 결과 단위로 완료 | 단계 프롬프트 |
| 단계마다 동일한 넓은 QA 지시 | 영향 행+필수 검사, 출시 기준 유지 | validation-policy, Q |
| 핵심 게임 원칙 여러 곳 반복 | 짧은 공통 불변 조건 + 상세 SRS 참조 | root AGENTS, 제품 SRS 보존 |
| 읽기 탐색/QA와 구현 절차 혼재 | 역할별 책임·권한·보고로 분리 | 세 TOML |
| 시각 품질을 코드/테스트로만 완료 처리할 위험 | 실제 전후 이미지·모션 영상 + 사용자 승인 별도 | visual skill |
| Figma URL/업로드 시도와 완료 혼동 | 편집 ID/재조회/렌더 단계 구분 | figma skill |
| 예상 실패를 이유로 무조건 승인/중단 | 승인된 로컬 작업은 진행, 실제 제품/권한 경계만 보류 | 공통·worker·총괄 템플릿 |
| 회사 계정·건강정보·실결제 경계 | 모든 역할에 유지; 삭제하지 않음 | 공통·운영·역할 |
| 글의 모델명/비용/사고율 | 역할을 먼저 고정, 모델 ID는 계정에서 추후 확인 | agent-setup |
| 이전 테스트 결과 | 역사 자료로만 보존 | references/v1.5, prototype-spec |

주요 현재 문서·설정의 검토용 diff(과거 아카이브·생성 로그 제외)는 `../validation/changes-v1.5-to-v1.6.diff`에서 확인한다. 이 파일은 승인된 운영 방향을 구체화한 내역이지 사용자 전역 파일 전체 감사의 결과가 아니다.
