# 현재 앱 전환 참조물

이 폴더의 파일은 **APP-01이 비교할 기준**이다. 제품 요구의 최상위 기준은 `../docs/arucon-SRS.md`다.

## current-art
- `approved-baby-character-sheet.png`: 현재 사용자가 유지하기로 한 크림색 아기형 인상/말캉함 참고.
- `approved-first-evolution-sheet.png`: 공통형 + 1차 4계열 시각 방향. 문서상의 새 이름은 말루/모노/피코/몽글이다. 이미지에 남아 있는 말랑형/시크형/쫑긋형/몽실형 표기는 과거 가칭이다.

중간에 생성됐던 녹색/파란색 계열 캐릭터 시트는 기준에 포함하지 않는다.

## floor-navigation-03
최신 웹 프로토타입의 소스·GLB·모션/바닥 입력 명세·핵심 테스트·시각 증거를 선별했다. 웹 앱 자체를 네이티브 앱으로 감싸라는 뜻이 아니다. **감각과 회귀 계약을 읽고 네이티브 렌더링에서 재현**한다.

검증된 웹 범위와 실제 모바일 앱 검증은 다르다. 이 폴더의 QA가 iOS/Android 설치형 앱 통과 증거가 되지 않는다.
