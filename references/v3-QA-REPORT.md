## 확인한 변경

예약된 두 프로필의 반쯤 덮인 눈/동그란 눈 표현이 구분되고, 조용한 프로필은 쓰다듬는 동안에도 반쯤 덮인 눈 모양을 유지한다. 눌림 이후 탄성값이 반대 방향으로 한 번 넘어갔다 수렴하는지, 귀의 지연이 몸과 다른지, 발이 바닥 아래로 밀리지 않는지 검사했다. 완전한 soft-body 물리, 미끄럼 없는 보행이나 충돌 역학을 검증한 것은 아니다.

카메라 가로 범위와 펫 크기 변경을 별도로 확인했다. 확장된 바닥의 입력 지점으로 이동하고 경계 밖 입력은 제한된다. 고정 가구에 대한 간단한 우회는 있지만 임의 가구 배치/일반 경로 탐색은 아니다.

자율 행동은 앞쪽/뒤쪽을 오가며 자원을 바꾸거나 완료되지 않은 교감 기록을 만들지 않는다. 움직임 줄이기는 배회와 탄성 반동, 환경의 미세 움직임을 제한한다. 필수 상태 전환은 여전히 표현한다.

브라우저 검사에서 무료 교감, 수동/자동급식 동일 규칙, 중복 섭취 방지, 화장실, 수면/깨우기, 여러 화면 크기와 패널 맞춤도 재확인했다. `engine.js`와 `config.js`는 원본 v2와 바이트 단위로 동일함을 확인했다.

## 실행 환경

Node.js 기본 test runner; Python Playwright + headless Chromium `/usr/bin/chromium`, `--use-angle=gl-egl --ignore-gpu-blocklist`. HTML을 about:blank에 주입하고 메모리 localStorage 대체물을 명시적으로 사용했다. 테스트가 실제 브라우저 출처의 디스크 저장이나 재설치 복구를 검증한 것은 아니다.

실제 iPhone/Android/Safari, 모바일 GPU, 발열/배터리, 실제 파일 앱에서 HTML을 여는 동작, 네이티브 빌드, 건강데이터, 서버와 클라우드 저장, 운영 출시 상태는 검증하지 않았다.

## 시각 검토

실제 렌더의 평상시/쓰다듬기/먹이 패널/수면 화면과 두 프로필의 확대 캡처를 확인했다. 캐릭터 및 방은 코드로 제작된 시안용 모델이며 최종 원화나 전문 리깅 납품물이 아니다.

동작 영상은 390×844 화면에서 실제 게임 코드를 1/24초씩 진행하여 645프레임, 약 26.9초로 만든 렌더다. 24fps는 인코딩 설정이며 실기기 측정 프레임 속도가 아니다. 장면 사이 프로필/위치 초기화가 있는 비교 영상이다. 동작 구간의 제목만 덧붙였으며 생성형 영상으로 결과를 꾸미지 않았다.
