# 아루콘 · 방 전체 이동 03

2026-09-18 · 활기찬 움직임 02에서 러그 바깥 바닥 터치를 수정한 웹 체험판입니다.

**캐릭터·츤데레 표정·이동 속도·말캉함·게임 계산을 유지합니다.** 모바일 네이티브 앱, 실제 건강정보 연동, 새로운 진화형을 만든 버전은 아닙니다.

## 바뀐 것

기존에는 화면에 바닥이 그려진 부분이라도 이동 허용 z 범위(-2.5~4.25)를 벗어나면 터치를 무시했습니다. 러그가 이동 경계인 규칙이 있던 것은 아닙니다. 실제 화면과 더 좁은 입력 좌표 범위가 일치하지 않았습니다.

이제 보이는 방의 바닥과 카메라·화면·메뉴를 기준으로 이동 영역을 정합니다. 러그 앞과 양옆, 뒤쪽 빈 바닥도 목적지로 지정할 수 있습니다. 화면 끝·가구 바로 옆을 누르면 펫이 화면 밖으로 잘리거나 물건에 겹치지 않는 가까운 빈 위치를 사용합니다. 벽·창문·메뉴는 바닥으로 처리하지 않습니다.

목적지에는 도착 전까지 작은 타원 표시가 보입니다. 표시는 터치를 가로채지 않습니다. 이동 중 다른 빈 바닥을 누르면 목적지가 바뀝니다. 식사·잠들기 중에는 동작을 강제로 끊지 않습니다.

## 실행

- `arucon-floor-navigation.html`: 코드와 모델을 포함한 단일 파일. 컴퓨터의 일반 브라우저에서 열어보는 용도입니다. 파일 앱 미리보기의 스크립트 실행은 보장하지 않습니다.
- `site/`: 기존 HTTPS 정적 사이트에 올릴 파일입니다. `index.html`, `sw.js`, `manifest.webmanifest`, `icons/`를 같은 루트에 유지합니다.
- 같은 개인 Wi-Fi 체험: Python 3.10 이상에서 `python serve.py --lan --open`; Windows는 `START-WINDOWS.cmd`. PC를 켜둬야 합니다. HTTP LAN에서는 오프라인 캐시를 사용할 수 없습니다.

**현재 배포된 Netlify 사이트를 이 작업에서 수정하지 않았습니다.** 이 폴더의 실행 파일과 공개 사이트의 버전을 혼동하지 마세요. 작업 환경의 Netlify 도구에는 이번 조회 시 읽기 기능만 노출되어 원격 쓰기를 수행하지 않았습니다. 로그인 보호·공개 범위·계정은 변경하지 않았습니다.

## 기존 사이트에 반영할 때

배포용 ZIP을 풀어 `index.html`이 바로 들어 있는 폴더를 기존 프로젝트에 사용합니다. 소스·테스트·문서·전체 작업 ZIP은 공개 사이트에 올리지 않습니다. 설정의 `FLOOR NAVIGATION · 03` 또는 휴대폰 점검의 `floor-navigation-03`으로 새 코드를 구분합니다.

서비스워커 캐시 버전은 파일 해시로 새로 생성됐습니다. 기존 캐시를 사용 중이면 기존 업데이트 안내를 통해 하던 동작을 마치고 저장한 뒤 새 버전을 적용합니다. 저장을 지우도록 요구하지 않습니다. 실제 설치 웹앱 업데이트·오프라인 재시작은 아직 미검증입니다.

## 저장과 변경 경계

같은 출처의 `arucon.life-room.v1` 저장 키와 버전 1을 유지합니다. 저장된 바깥 바닥 좌표도 복구할 수 있도록 위치 검증만 확장했습니다. 더 좁은 화면으로 바뀌면 표시 위치를 안전 범위로 보정합니다. 먹이·코인·EXP·급식·수면·동면 계산, 저장된 게임 원장과 성격 선택은 그대로입니다.

이전 버전으로 롤백하면 이전 코드가 새 바깥 좌표를 표시용 위치로 인정하지 못할 수 있습니다. 그 경우 기존 로직에 따라 표시 위치만 기본값을 사용하며, 이 변경으로 게임 재화를 초기화하지 않습니다. 도메인 데이터나 브라우저 기록의 영구 보존을 보장하는 서버 동기화는 아닙니다.

## 확인 순서

러그 아래 빈 바닥 → 양옆 가장자리 → 창가 쪽 바닥 → 다른 바닥으로 이동 중 재지정 → 식탁/쿠션 → 쓰다듬기를 확인합니다. 벽과 버튼을 눌렀을 때 원하지 않는 이동이 없어야 합니다. `docs/DEVICE-TEST.md`의 기존 실기기 항목도 참고합니다.

자동 검사는 Chromium의 실제 DOM 입력, HTML 주입과 명시적인 메모리 저장소로 실행했습니다. 실제 iPhone/Android/Safari, 실제 디스크 저장, 이 수정판의 원격 배포·설치는 미검증입니다. 영상의 12fps는 출력 설정이며 기기 성능 수치가 아닙니다.
