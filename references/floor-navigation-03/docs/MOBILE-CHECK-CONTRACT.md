# MOB-01 · 휴대폰 체험 준비 범위

기준: 생활 연결 01 및 SRS v1.6의 FR-10.1 / FR-16 / FR-4·18 / FR-NF.6. 사용자의 “좋아 다음가자” 요청에 따라 바로 전 단계에서 제시한 휴대폰 체험·터치·복귀 확인을 준비했습니다.

## 구현

- 기존 GLB, 게임 엔진·config, 장면/모션 코드를 보존하고 주변 실행 코드만 변경합니다.
- 주 조작부는 최소 44px, 현재 펫 입력 영역은 모델 표시보다 크게 유지합니다. 시각적 캐릭터 확대는 하지 않습니다.
- 기본 포인터 1개만 쓰다듬기를 소유합니다. 보조 터치·오른쪽 클릭이 시작하거나, 다른 포인터 해제가 현재 터치를 끝내지 않게 합니다.
- `visibilitychange`/`pagehide`의 중복 정지가 최초 부재 시각을 덮어쓰지 않으며 숨김 중 저장도 같은 시각을 보존합니다. `pageshow`/`visibilitychange`의 중복 복귀는 한 구간을 한 번만 정산합니다.
- 숨김 시 예약된 requestAnimationFrame을 취소하고 복귀 때 다시 시작합니다. 새 그림 생성이나 성격 연기를 바꾸는 작업이 아닙니다.
- 시연 패키지는 새 네이티브 프레임워크 채택 승인이 아닙니다. React Native, 게임 엔진, 서버, 서명/스토어 배포 선택은 별도 결정입니다.

## 경제·시간 불변식

직접/자동 식사의 조건과 효율, 기존 재고 소비, 식사 결과 선확정과 연출 확인 분리, 무료 교감, 자동화 비서열화, 동면과 분 단위 시연 시간은 유지합니다. 점검·렌더 샘플링·서비스 워커·홈 화면 실행은 보상을 생성하지 않습니다.

## 새 기술 설정의 지위

DPR/요청 빈도 옵션, 점검 UI, 캐시 버전, 로컬 서버 포트는 테스트 인프라 설정입니다. 운영 성능 목표·배터리 예산·정식 지원 OS·갱신 정책을 확정한 값이 아닙니다. `service worker ready`는 자산 캐시 등록 상태이지 실제 휴대폰 오프라인 테스트 통과가 아닙니다.

## 완료 / 보류

소스와 실행 패키지 작성, 범위별 자동 검사, 실제 브라우저 렌더 이미지 확인까지 진행합니다. 실제 사용자 기기의 실행·홈 화면 설치·오프라인·진짜 출처의 디스크 저장 지속성은 사용자의 개인 기기에서 확인해야 하며 미검증으로 남깁니다. 공개 배포에는 대상 계정·사이트·범위 확인이 필요합니다. 회사 계정 접근·Figma 수정·Git/스토어 배포를 포함하지 않습니다.
