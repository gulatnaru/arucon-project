# 다음 앱 작업으로 넘기는 기준

## 고정할 기준

- 크림색 아기형·츤데레 얼굴·말캉한 110/15 입력·active-motion-02 속도 정책은 최근 사용자 피드백 기준을 유지합니다.
- 이 버전은 FR-10.1의 바닥 입력 불일치를 해결하는 웹 수정판입니다. 네이티브 빌드·건강정보·동기화를 이미 구현한 상태가 아닙니다.
- 화면을 카드형 대시보드로 되돌리거나 펫·진화형을 다시 디자인하지 않습니다.

## 다음 독립 작업

실제 개발 저장소에서 앱 기술 검증 계획을 작성하고, 3D 자산과 입력/도메인 경계를 보존할 최소 경로를 제시합니다. 앱/렌더러 스택·지원 OS는 SRS DEC-12/31에 따라 결정하며, 이 문서가 특정 프레임워크를 자가 승인하지 않습니다.

선택된 환경에서 방 1개·펫 1마리를 구동하는 작은 빌드를 먼저 확인합니다. 가능하면 같은 작업에서 렌더링, 빈 바닥 이동, 쓰다듬기, 화면 정지/복귀, 로컬 저장을 확인합니다. 첫 연결에는 합성 데이터만 사용하고 실제 건강정보·결제·서버 권한은 추가하지 않습니다.

## 완료 증거

설치/실행 가능한 빌드 또는 정확한 실패 로그, 사용한 장치/에뮬레이터, 아루콘 외형·속도 보존 비교, 도메인/입력 계약을 남깁니다. HTML을 단순 WebView로 감싼 것을 고품질 네이티브 아트 완료로 보고하지 않습니다.

이번 웹 원본에서 게임 엔진·모델·모션 정책을 분리해 넘길 수 있지만, 운영 트랜잭션/헬스 연동/진화 산식은 미정 상태를 유지합니다.
