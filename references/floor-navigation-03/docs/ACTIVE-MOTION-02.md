# 아루콘 · 활기찬 움직임 02 — 적용 계약

작성일: 2026-09-18. 사용자 요청: 둔한 느낌을 줄이고 더 빠르고 액티브하고 부드럽게. 기존 개인 Netlify 프로젝트에 직접 배포 요청.

## 수정 범위
외형·기본 메시·재질·모핑 데이터와 GLB의 15개 클립을 유지한다. 이번에는 실행기의 이동·재생 시간·보간·프레임 일정과 변형 계산만 변경한다. 게임 엔진·경제 config·저장 키/버전·부재 계산은 유지한다. 새로운 수치는 이 PROTO의 연출 조정값이며 운영 밸런스가 아니다.

| 항목 | 이전 | 이번 |
|---|---|---|
| 츤데레 이동 상한(월드 단위/초) | 0.92 | 1.55 |
| 솔직한 성격 이동 상한 | 1.10 | 1.72 |
| 츤데레 인사 도입부 재생 | 1.35초 | 약0.48초. 힐끗/딴청 포즈는 그대로 샘플링 |
| 방향 전환 응답 | 8 | 12 |
| 가속 응답 | 10 | 14 |
| 연속 경로 지점 | 매번 속도0으로 초기화 | 연속 이동이면 속도 유지, 방향에 따라 감속 |
| 기본 포즈 블렌드 | 0.20초 | 0.14초 |
| 자율 행동 대기(츤데레/솔직) | 11/8초 | 5.8/4.3초. 움직임 줄이기에서는 정지 |
| 직접 눌림 스프링/감쇠 | 110/15 | 110/15 유지, 1/120초 이하 적분 |
| 손을 뗀 뒤 후속 반응 | 2.9초 | 2.1초 |
| 기본 그리기 요청 상한 | 40 | 60. 실제 달성 FPS 보장 아님 |
| 가벼운 모드 상한 | 30 | 30 유지 |

모든 동작을 같은 배속으로 돌리지 않는다. 수면 1.08배, 깨우기1.25배, 먹기1.2배, 성격 제스처는 단계별1.3~2.8배의 **시각 재생**만 적용한다. 게임 시간/식사량/EXP는 배속하지 않는다.

## 부드러움
프레임 건너뛰기의 기준 시각을 누적하여 60Hz 입력을 불필요하게 30Hz로 만드는 패턴을 제거한다. 렌더링이 늦었을 때에도 정상적인 100ms의 시간차를 50ms로 줄이지 않고 시각 적분에 반영한다. 긴 정지 후에는 최대120ms만 진행하고 화면 숨김/복귀는 기존 정지 처리를 따른다. 큰 dt 한 번으로 스프링이 발산하지 않도록 시각 시뮬레이션을 1/120초 이하로 나누며, 메시 변형은 렌더당 한 번 적용한다.

부위별로 실제0이 아닌 morph target만 계산하고 유효 가중치가 같으면 메시/버퍼를 다시 갱신하지 않는다. 원본 GLB 바이트는 변경하지 않는다.

## 성격/기능 경계
츤데레는 잠깐 힐끗 보고 움직이며, 시선 피하기·몸 기대기를 유지한다. 장시간 지연과 까칠함을 동일시하지 않는다. 직접/자동급식·무료 교감·청결·동면·저장 규칙은 이전 그대로다. 실행 파일에는 실제 건강 데이터·계정·결제·서버 동기화가 없다.

## 검증 의미
동일 초기 위치에서 가구를 피하는 이동/인사/식사 전환을 이전·수정판에서 측정한다. 표의 실제 비교 시간은 **시뮬레이션 시간**이며 실기기 입력 지연/성능 측정이 아니다. 기능 검사·시각 자체 검토·사용자 촉감 승인은 별개다.
