# 방 전체 이동 03 — 수정 계약

## 승인된 피드백과 범위

사용자는 배포된 이전 버전에서 이동·쓰다듬기 속도의 개선을 확인하고, 원 이외의 위치를 눌렀을 때 오지 않는 문제를 보고했습니다. 개선된 속도와 탄성을 유지한 채 해당 입력 문제를 수정합니다. 모든 기기에서의 성능이나 저장까지 승인됐다는 의미는 아닙니다.

## 재현 및 원인

390×844 CSS 픽셀 화면에서 (195,660)을 누르면 바닥 z≈6.4323에 해당합니다. 이전 입력은 z>4.25를 무시해 8초를 진행해도 아기형이 z=1.8에 머물렀습니다. 뒤쪽과 앞쪽의 일부 빈 바닥도 동일한 하드코딩 범위 때문에 제외됐습니다. `tests/baseline-floor-probe.json`에 원본 코드의 실제 입력 결과를 기록했습니다.

## 구현

- `src/renderer.js`: 고정 직교 카메라의 두 바닥 축을 함께 역변환합니다. CSS 좌표를 사용하며 유효하지 않은 입력을 거부합니다. 셰이더·모델 재질·그리기 속도는 변경하지 않았습니다.
- `src/room-scene.js`: 기존 바닥 메시와 벽의 좌표 범위를 표시합니다. 방 모델·가구 위치·러그 크기는 그대로입니다.
- `src/app.js`: 바닥 판정 → 화면 내 안전 경계 → 가까운 빈 좌표 → 이동 경로 순으로 처리합니다. 메뉴와 펫의 터치는 우선하며, 도착점 표시와 접근 가능한 짧은 상태를 추가합니다.
- `src/navigation.js`: 화면 가장자리와 가구 안 목표를 가까운 빈 좌표로 조정하고 비정상 입력을 거부합니다.
- `src/room-actor.js`: 확장된 영역의 화분 충돌 범위를 추가하고 유효 경로가 없는 이동은 성공으로 보고하지 않습니다. 모션의 속도·대기·보간·110/15 스프링 정책은 보존합니다.
- `src/session.js`: 넓어진 바닥 위치를 읽도록 표시용 위치 검증만 확장합니다. 재화·원장·저장 버전 변경은 없습니다.
- `src/index.template.html`, `src/styles.css`, `src/mobile.js`: 도착점과 버전 식별을 추가합니다. 도착점은 클릭을 가로채지 않으며 항상 표시하는 새 관리 패널은 없습니다.

## 수용 기준

FLOOR-01: 러그 밖의 앞·좌·우·뒤 빈 바닥 입력을 수락하고 표시한 목표로 도착합니다.
FLOOR-02: 화면 끝에서는 펫의 입력 영역을 화면 안·메뉴 위에 유지하는 가까운 지점을 사용합니다.
FLOOR-03: 벽·창문은 바닥으로 변환하지 않고, 식탁·쿠션·버튼 고유 동작을 보존합니다.
FLOOR-04: 기존 가구와 화분의 고정 충돌 영역을 지나가지 않습니다. 자유 가구 배치·물리는 범위 밖입니다.
FLOOR-05: 이동 중 새 바닥 터치는 목적지를 바꿀 수 있으나 식사·수면·주 포인터 교감을 깨지 않습니다.
FLOOR-06: 새 위치의 저장·복구·화면 변경은 표시 위치만 다루며, 게임 수치와 원장은 변하지 않습니다.
FLOOR-07: 외형·시크한 눈매·탄성·개선된 속도를 보존합니다.

기본 크기·히트 영역 여유·길찾기 격자 간격은 시제품 구현 설정이며 출시용 새 밸런스 승인이 아닙니다. 모든 입력이 문자 그대로 터치 픽셀 중앙까지 갈 수 있다고 약속하지 않습니다. 불가한 위치는 안전한 가까운 바닥으로 조정합니다.
