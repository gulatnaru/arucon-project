# 문서 검증 보고 — 아루콘 v1.5

작성일 2026-09-17 · **문서 정합성 검사 27/27 통과**

## 무엇을 확인했는가

기존 SRS v1.4의 장 구조 0~14와 기능 ID를 보존했고, 원문 게임 밸런스 config 블록은 변경하지 않았다. 기존 수용 기준 166개를 유지하고 48개를 추가하여 **214개 고유 테스트 ID**를 확인했다. 새 결정 DEC-27~31의 연결, DEC-30 제안/DEC-31 OPEN 상태, 모바일/확장 완료 기준 분리, 로컬 Markdown 링크와 SVG 문법을 검사했다.

기준으로 사용한 v1.4 사본과 원본 첨부 SRS의 해시가 일치한다. 이 작업에서 원본을 덮어쓰지 않았다. 문서에 내부 도구 인용 핸들이 남아 있지 않고, 패키지에 글꼴 파일은 없다.

## 실행 근거

- Python 표준 라이브러리 기반 `check_documents.py`를 실행했다.
- 결과: `document-checks.json`.
- 실행 명령:

```sh
python validation/check_documents.py --baseline /path/to/arucon-v1.4/docs --original-srs /path/to/original-v1.4-SRS.md
```

이번 실행에서는 `/mnt/data/arucon-update-work/arucon-v1.4/docs`와 `/mnt/data/arucon-v1.4/docs/arucon-SRS.md`를 읽기 전용 기준으로 사용했다. 명령의 두 경로는 검증자가 가진 v1.4 자료 위치를 가리키면 된다.

## 보드 렌더 확인

SVG를 로컬 PNG로 렌더해 한글·줄맞춤·카드 간격·내용 가림을 시각 확인했다. 첫 렌더의 한글 글꼴 문제를 수정하고 다시 렌더했다. 글자 포함 SVG와 외곽선 SVG 모두 XML 파싱을 통과했다. **이것은 Figma 내부 가져오기/렌더 검증이 아니다.**

## 확인하지 않은 것

- 214개 게임/플랫폼 수용 기준의 실제 실행: **미실행**. 문서 체크 통과와 다르다.
- PC 설치/입력 통과/OS 렌더, iOS/Android 실제 위젯, Android 배경 서비스/런처·전력: **미구현·미검증**.
- 신규 기기 연결/철회·서버 읽기 토큰·실제 건강 데이터 처리: **설계/미정 상태**.
- 기존 v3 코드 회귀 재실행: **하지 않음**. 과거 QA는 references의 당시 범위로만 보존했다.
- Figma 원격 개정: **실패**. 조회는 일부 성공, 편집 한도와 업로드 DNS 실패. `../figma/FIGMA-STATUS.md` 참조.

추가 제안 규칙의 승인, 사람이 느끼는 시크함/말캉함/업무 방해 여부, 법률/의료/스토어 적합성을 정적 문서 검사로 입증하지 않는다.
