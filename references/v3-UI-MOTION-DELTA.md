# 작은 방 03 — 화면·성격·모션 수정 계약

## 기준

이 대화의 최신 피드백을 반영한 시연용 수정이다. v1.4 경제·자동 돌봄 원칙을 유지한다. 신규 운영 밸런스, 진화 규칙, 사람 MBTI 판정은 추가하지 않는다. v1.2의 수동 급식 전용·쓰다듬기 체력 소모 규칙으로 되돌리지 않는다.

## 룸 구성

방은 휴대폰 콘텐츠 영역 전체를 사용한다. 메인 UI를 늘리지 않는다. 캐릭터를 줄이는 동시에 눈/입의 명도 대비와 선 굵기를 조정한다. 캐릭터 모델 배율, 카메라 폭, 가구 위치, 이동 범위를 함께 조정해야 하며 그림 크기만 줄인 채 좁은 중앙에서 움직이게 두지 않는다.

이번 비교 수치: 모델 0.82, 카메라 가로 6.8. 바닥 목표 좌표 x=-2.65…2.65, z=-2.5…4.25. 가구의 접근점과 터치 영역도 동일한 배치 정보를 참조한다. 이 수치는 승인된 최종 디자인 토큰이 아닌 시연값이다.

## 표정의 정체성

조용한 아이는 건강한 각성 상태에서 반쯤 덮인 눈과 작은 일자 입을 기본으로 한다. ‘시크함’은 졸림/청결로 인한 시무룩함/아픈 상태와 같지 않다. 기본적으로 눈을 완전히 감거나 축 처진 자세로 만들지 않는다. 쓰다듬기 때 짧은 만족 눈깜빡임은 가능하지만, 주된 표정은 유지한다. 볼과 하트 효과는 적극적 프로필보다 절제한다.

두 프로필의 몸과 종족 정체성은 같으며 현재는 개발용 표정·동작 비교다. 특정 진화형에 특정 성격을 영구 고정하는 규칙을 추가하지 않는다.

## 말캉한 동작

‘눌림 → 원래 형태를 살짝 지나치는 반동 → 멈춤’을 한 동작으로 검증한다. 손 방향으로 기울기, 귀가 뒤늦게 따라오기, 발이 바닥에 남기, 배의 볼륨 변화를 서로 다른 노드로 제어한다. 모든 부위를 하나의 그림처럼 같이 확대/회전하는 방식만으로 끝내지 않는다.

시연은 감쇠 스프링과 절차적 부위 변형이다. 실제 soft-body 시뮬레이션, 미끄럼 없는 역운동학 보행, 전문 리깅 작업을 완료했다는 의미가 아니다. 발 접촉 검사는 발이 바닥 아래로 내려가지 않는 최소 검증이며 완전한 접촉 역학 검증은 아니다.

## 생동감의 리듬

대기 중 짧은 살피기, 귀 움직임, 앉기, 기지개, 창 쪽/방 앞쪽으로 이동하기가 섞인다. 동작 사이 휴지 시간을 둔다. 조용한 아이의 생동감을 ‘빠른 이동과 과한 표정’으로 대체하지 않는다.

환경은 구름·커튼·잎 등 작은 부위만 움직인다. 방 전체 카메라 흔들기나 지속적인 큰 입자 효과는 추가하지 않는다. 동작 줄이기와 탭 숨김 시 불필요한 표현을 제한한다. 자율 행동은 EXP·재화·기분 보상이나 가짜 생활 기록을 만들지 않는다.

## 검증

정상 대기, 눌림, 반동, 이동, 수면을 작은 실제 화면에서 볼 것. 세로 화면 390×844의 이전/이후 비교를 함께 제공한다. 정지 화면에서 표정이 구분되는지, 동영상에서 귀와 몸의 타이밍이 다른지 각각 확인한다. 자동 검사 통과만으로 캐릭터의 매력이나 자연스러움을 승인하지 않는다.

## Figma 인계

현재 Figma 파일의 자동 편집은 이 변경판에 포함되지 않았다. 실행판 미리보기와 본 계약을 UI 설계 작업의 비교 자료로 사용할 수 있지만, 펫의 실제 움직임은 Figma의 단순 화면 전환과 구분한다.
