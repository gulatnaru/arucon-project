## 사용자 실제 피드백

- 이전보다 좋아졌지만 움직임 형태가 단조롭고 표정이 자주 변하지 않는다.
- 대사가 거의 없고 터치 반응이 비슷하며 대화창이 어색하다.
- 아기는 더 까불거리고 호기심 많은 아기여야 한다.
- 현재 크기는 너무 작다. 이전 버전보다는 작되 지금보다 커야 한다.
- 성장기/진화 후 외형이 비슷하고 아기보다 확실히 커야 한다.
- 눈이 튀어나와 외형 완성도가 낮고 예쁘지 않다.
- 새 행동이 드물어 잠깐 관찰하면 성장 차이를 알기 어렵다.
- 모자 착용 연출이 어색하고 기억이 행동으로 체감되지 않는다.
- AI/지능이 생겼다는 느낌이 아직 없다.

## 이번 제작 범위

1. **아기 한 마리**부터 완성한다. 성장기/진화형 전체 재작업은 아기 검토 뒤로 미룬다.
2. 현재 v7 대비 **+15%, +25%, +35%**를 같은 카메라·방의 실제 게임 화면에서 비교한다. 사용자 선택 전 최종값을 고정하지 않는다.
3. 얼굴을 다시 디자인한다. 눈의 돌출 느낌을 없애고 눈꺼풀/눈매/볼/입이 한 얼굴 볼륨에 자연스럽게 들어간다. 작은 유니콘형 뿔 하나 유지.
4. 실제 로컬 Blender/MCP 가능 여부를 확인한다. 가능하면 모델/morph/motion을 수정하고 편집 소스·GLB 함께 보존. 불가능하면 기록하고 코드 좌표 조정만으로 완성 아트라고 하지 않는다.
5. 아기의 핵심은 **호기심 많고 까불거리지만 사람을 좋아하는 작은 아기**. 시크함은 성장하며 드러나며 아기부터 무표정·무기력하게 만들지 않는다. 일반 저장의 personality ID를 교체하지 않는다.
6. 자율 생활은 관심→행동→결과→반응→다음 상태로 연결한다. 두리번거림/관심 대상 발견/짧은 통통 접근/너무 가까워 놀람/몸 털기·정리/사용자 확인/다른 관심/짧은 장난/편한 휴식. 단순 walk/idle 또는 무작위 clip 재생으로 대체하지 않는다.
7. **호기심/신남/장난기/놀람/만족/민망함/졸림**을 실제 얼굴과 행동으로 구분한다. 작은 게임 크기에서 안 읽히는 expression ID 변경은 실패다.
8. 머리/몸·현재 행동·최근 터치·직전 완료 경험에 따라 반응·후속 행동을 달리한다. 동일 눌림→동일 대사→복귀 반복 금지. 연타 EXP/애정/보상 없음.
9. 대사는 더 자주 나올 수 있지만 항상 말하지 않는다. 같은2~4문장 순환을 없애고 실제 관심·행동·최근 경험·성장 단계에 연결한다. 행동 우선, 외부 자유 대화 없음.
10. 작은 예쁜 말풍선을 펫 주변에 둔다. 방/펫/얼굴을 가리지 않고 개발 카드·큰 패널처럼 보이지 않는다. Figma가 실제 사용 가능하면 UI 비교에 활용하되 계정·권한·외부 전송 경계를 확인한다.
11. 쿠션 이동·모자 재착용은 완료 경험 때문에 다음 행동이 달라졌음을 사용자가 행동으로 추론할 수 있게 한다. 현재 위치/소유/상태는 기존 서비스가 권위이고 취소·다른 개체의 기억을 사용하지 않는다.
12. AI B 통합은 완료 조건이 아니다. A로 먼저 지능감을 표현하고 기존 온디바이스 연구/증거는 보존한다.
