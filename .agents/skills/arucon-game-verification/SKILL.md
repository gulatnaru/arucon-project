# 게임 규칙 검증

## 완료 조건
영향받는 FR/승인 DEC/AT와 실제 변경을 매핑한다. 관련 검사와 저장소 필수 검사가 통과하고, 실행 명령·환경·결과·증거가 남는다. 미결정·환경 부족은 별도로 보고한다. 모든 경우에 전체 게임 테스트를 실행하는 규칙이 아니다.

급식이면 직접/자동 조건·효율·마지막 재고·중복 확정, 시간 변경이면 수면/동면 경계·구간 분할, 저장 변경이면 원자성·재시도·복구의 관련 사례를 포함한다. 교감 입력에 닿으면 자원 중립을 확인한다.

## 기본 절차
1. 저장소 루트의 `docs/validation-policy.md`, `validation/commands.json`에서 해당 범위를 고른다. 이 스킬 본문은 검증 작업에만 읽는다.
2. 관련 기존 테스트와 기대값의 SRS 근거를 확인한다. 필요한 회귀 테스트를 추가하되 현재 구현을 그대로 복사해 통과시키는 테스트는 만들지 않는다.
3. 실제 있는 명령을 올바른 cwd와 합성 fixture에서 실행한다. 범위 안 회귀를 수정·재검사하고 범위 밖 실패를 분리한다.
4. `templates/completion-report.md`에 결과와 미실행을 기록한다. 더 나은 절차가 있으면 바꾸어도 완료 조건은 유지한다.

## 보호 경계
SRS·밸런스·기대값을 자가 승인하지 않는다. 실제 건강정보/운영 DB를 테스트 입력으로 쓰지 않는다. 테스트 제거·완화로 성공시키지 않는다. 원격 접근이나 정책 변경은 이 스킬의 권한이 아니다.
