# Figma 반영 확인

## 완료 조건
현재 승인된 계정·지정 파일·변경 범위를 확인하고 실제 생성/편집 ID를 얻는다. 하위 노드 재조회와 화면별 렌더로 내용을 검증한다. 미완료 단계는 그대로 표시한다. 공유 권한 확대나 게임 실행 이식은 포함하지 않는다.

## 기본 절차
1. `templates/figma-task.md`와 이번 사용자의 외부 쓰기 승인을 대조한다. 승인이 없으면 계획/로컬 산출물만 만들고 원격 쓰기를 시작하지 않는다.
2. 현재 연결 계정과 대상 파일/하위 노드를 조회한다. 계정이 다르거나 판단 불가이면 쓰기 전에 멈춘다. 계정 불일치를 다른 팀·파일 생성으로 우회하지 않는다.
3. 실제 도구 스키마와 해당 연결의 필수 스킬을 로드하고 작은 변경 단위로 수행한다. 기존 객체와 사용자 작업을 보존하고 영향 노드 ID를 기록한다.
4. 쓰기 성공 후 하위 구조와 렌더를 확인한다. 이미지 업로드 URL 발급이나 로컬 PNG 생성은 이 단계를 대신하지 않는다.
5. 결과를 접근/대상/쓰기/재조회/시각검증으로 구분하고 파일·노드 링크와 차이점을 보고한다.

## 중단과 부분 성공
권한/한도/네트워크 실패는 오류 근거와 마지막 성공 ID를 기록한다. 쓰기 후 확인이 막히면 “반영됨·검증 미완료”이고 반복 쓰지 않는다. 하위 노드를 확인하지 못한 파일을 빈 파일이라고 단정하지 않는다. 다른 계정·비밀 토큰·비인가 경로로 우회하지 않는다.

## 호출·권한 경계
자동 선택은 OFF다. 명시적 호출도 사용자 승인·MCP 권한·샌드박스를 대체하지 않는다. 이 스킬은 Figma 연결을 설치하거나 도구 이름을 보장하지 않는다. 사용 가능한 도구를 실제 조회한다. 래스터 캡처·편집형 디자인·Rive/3D 리소스·앱 빌드를 구분한다.
