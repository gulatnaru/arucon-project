# 디자인·시안 인계 — 아루콘 v1.6

이 문서는 도구별 최신 기능을 보장하는 안내가 아니라 아루콘 산출물의 범위 지시문이다.

## 시안의 목적

모바일은 전체 화면 방과 작은 펫, PC는 작은 방/펫만 보기, 위젯은 상태 스냅샷, Android 배경화면은 선택적 검토 화면으로 구분한다. 수면/먹이/코인/연결 정보는 합성 데이터만 사용한다. 실제 건강 데이터·비밀키·회사의 디자인 파일을 사용하지 않는다.

## 비교 기준

조용한 아이의 반쯤 감긴 눈·작은 일자 입을 유지한다. 말캉함은 접촉/멈춤에 따라 자연스럽게 안정되고, 계속 온몸을 늘리는 효과로 대신하지 않는다. 환경은 미세하게 움직이며 충분한 휴식 구간이 있어야 한다.

PC 투명 영역·항상 위·클릭 통과의 **시안 설명**과 실제 OS API 구현을 구분한다. Figma 정지 화면에 버튼 연결을 넣은 것은 화면 흐름 시연이지 실행형 PC/위젯/배경 서비스가 아니다.

## 납품 시 표시

편집 가능한 텍스트/벡터·재사용 컴포넌트·래스터 캡처 범위를 각각 밝힌다. 실제 게임 영상·스크린샷과 새로운 디자인 시안을 혼동하지 않는다. 공개 웹 게시/공유 변경은 별도 명시적 승인 없이는 하지 않는다. 이번 Figma 반영 상태는 `../figma/FIGMA-STATUS.md`를 따른다.


### v1.6 개발 운영 보완

제품 범위와 시각 요구는 유지한다. 관련 절을 선택해 읽고 `validation-policy.md`에 따라 기능/시각 증거를 분리한다. 이번 작업은 문서·역할·스킬 설정만 작성했으며 코드·실기기·Figma를 새로 실행한 결과가 아니다. 외부 편집 요청은 `../.agents/skills/arucon-figma-handoff/SKILL.md`와 실제 연결 도구 지침을 함께 적용한다.
