# REBOOT-04 성격 기반과 대표 3종

게임용 펫 성격의 검토안이다. 인간 MBTI 검사나 건강 진단이 아니다. [작업 지시](../tasks/REBOOT-04-personality-foundation.md), [실행 결과](../REBOOT-04-REPORT.md)를 따른다. 일반 저장의 성격 ID와 기존 성장·경제 정책은 변경하지 않는다.

## 구조와 형성

기존 RebootDirector, BabyPlan, BabyLines, RebootMemoryStore를 확장했다. 별도 경제 엔진·DB·대사 선택기·LLM은 만들지 않았다.

네 연속축 approach / play / company / novelty는 각각 외향↔내향, 장난↔차분, 함께함↔독립, 탐색↔안정을 나타낸다. 범위는 [-1,1], 저장 버전은 1이다. 부호 조합의 16주소는 확장키이며 완성된 16유형 목록이나 실제 MBTI 코드가 아니다.

성장 인터페이스의 stage / maturity는 아기 0, 성장기 .5, 진화 후 1이다. 대표 설계는 아기의 조심스러운 확인이 성장 후 익숙한 접근으로 이어지는 것이다. 이번 실행은 공통 아기 Lv.1의 3종 비교다. 성장기·진화형 자산과 레벨별 신규 콘텐츠는 구현 범위가 아니다.

각 유형은 서로 다른 6개 인과 시퀀스, 6개 접촉 동작 후보, 6개 이상의 얼굴 패턴을 지원한다. 기존 표정 morph와 몸·발·도약·정돈 동작을 재사용하며 진행 순서와 후속 행동을 바꾼다. 대사 수나 ID만으로 장면을 세지 않는다. 자동 검사로 후보 도달성을 검증하고, 실제 관찰된 부분은 실행 보고서에서 별도로 센다.

행동 선택은 네 축, 깨어 있는 상태, 이동·접촉, 현재 방 대상과 최근 2장면을 읽는다. 머리·몸 접촉은 진행 중 장면, 같은 개체의 완료 손 기억, 최근 2접촉 스타일도 읽는다. 의도는 완료나 취소까지 유지한다. 짧은 탭에도 후속 몸짓이 이어지며 이동·메뉴·수면·앱 전환은 취소할 수 있다.

발화 표시 이력과 실제 행동 완료 기억은 구분한다. 대화가 호흡·표정·일반 입력을 전역으로 정지시키지 않는다. 선택이나 DB 쓰기를 매 프레임 실행하지 않는다. 취소된 장면은 완료 기억이나 보상을 만들지 않는다.

## 저장·실패·비교

기존 격리 arucon-reboot-review.db의 JSON 기억에 성격 기반과 RNG 상태를 저장한다. petId·버전·유한 축 값·64개 사건·32KiB 한계를 검사한다. 처음/최근 사물 경험을 기존 크기 한계 안에 보존한다. 원장은 기존 서비스와 공통 SQLite 대기열을 사용한다. 단순 기억 저장 실패를 경제 성공으로 바꾸거나 원본 DB를 초기화하지 않는다.

쿠션 배치는 UI 클릭 시점의 오래된 revision을 대기열에 들고 가지 않고, 실행 시점의 최신 기억을 읽는다. 취소 epoch와 저장 가드는 유지한다. 오래된 위치는 확인 시선에만 쓰고 접근·정착·완료 기억은 현재 쿠션 위치를 사용한다.

3종 모두 같은 방, 공통 네발 GLB, +35 크기, DPR2.5/AA0, 일반 모션에서 비교한다. 제목은 모두 아루다. 성격명은 검토 메뉴에만 있고 말풍선 가리기로 비언어 비교가 가능하다. 개체별 실제 관찰 이력은 보존하며, 영상마다 누적 이력과 조작 시점을 기록한다. 초기화로 동일 이력을 꾸미지 않는다. 최종 크기·렌더 설정은 이 검토로 확정하지 않는다.
