# 아루콘 — 프로토타입 상태 인덱스

버전 v1.6 · 2026-09-17

이 묶음은 **문서 개정본**이다. 브라우저 v3 코드를 수정하거나 새 네이티브 앱을 제작하지 않았다.

| 산출물 | 실제 범위 | 이번 상태 |
|---|---|---|
| 최초 생활 웹 시제품 v1.4 | SVG/CSS·2성격·가구/자동급식·합성 경제 | 역사적 계약을 [원문](../references/v1.4-prototype-spec.md)에 보존 |
| 작은 방 브라우저 v3 | 절차 생성 WebGL·넓은 방·작은 펫·시크한 표정·말캉한 연출 | 기존 사용자 제공 소스/영상. [시각 변경](../references/v3-UI-MOTION-DELTA.md)·[당시 QA](../references/v3-QA-REPORT.md) 참고 |
| PC 설치형 동반 앱 | 같은 펫 읽기·무료 교감·두 모드 | 요구 정의. 구현/실기기 검증 없음 |
| iOS/Android 실제 홈 위젯 | 같은 펫 상태 스냅샷과 앱 진입 | 요구 구체화. 이번 작업에서 구현/실기기 검증 없음 |
| Android 라이브 배경화면 | 아이콘 뒤의 방과 제한적 반응 | 선택적 검토. 실제 설정/전력 검증 없음 |
| Figma v1.5 요건 보드 | 플랫폼 역할·UI 방향·확장 경계 | 로컬 SVG 완성. 원격 상태는 [Figma 보고](../figma/FIGMA-STATUS.md) 참고 |

역사 문서의 상대 경로는 **해당 시제품 패키지 기준**이며 본 문서 묶음에는 전체 실행 코드와 영상이 포함되어 있지 않다. 과거 테스트 수는 당시 코드·환경의 결과로만 해석하고 신규 PC/위젯/배경화면에 전용하지 않는다.

정식 기능 검증은 `acceptance-tests.md`에 설계되어 있으며, 이번 개정의 실제 문서 검사는 [검증 보고](../validation/WORKFLOW-QA.md)에 기록한다.


### v1.6 개발 운영 보완

제품 범위와 시각 요구는 유지한다. 관련 절을 선택해 읽고 `validation-policy.md`에 따라 기능/시각 증거를 분리한다. 이번 작업은 문서·역할·스킬 설정만 작성했으며 코드·실기기·Figma를 새로 실행한 결과가 아니다. 외부 편집 요청은 `../.agents/skills/arucon-figma-handoff/SKILL.md`와 실제 연결 도구 지침을 함께 적용한다.
