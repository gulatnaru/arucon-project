# 아루콘 — 팀 공유 요약 v1.7

**건강한 일상으로 생활을 마련하고, 자기 성격대로 살아가는 작은 친구와 함께하는 게임.**

걷기·달리기로 먹이와 코인을 얻고, 펫이 실제 먹이를 먹어 성장한다. 직접 급식과 opt-in 식탁 자동급식의 효율은 같고, 가벼운 쓰다듬기·인사·관찰은 무료다. 화장실과 가구는 반복 작업을 줄이고 생활 장면을 늘린다.

**현재 캐릭터:** 진화 전 공통형의 표시명은 **아루콘**. 1차 외형 대명사는 **말루(낮고 넓음), 모노(세로형·비대칭 귀), 피코(두 귀가 위로 섬), 몽글(둥근 귀·말린 꼬리)**. 사용자가 지은 `구름콘` 같은 개체명은 진화 후에도 유지한다. 형태명은 성격명이 아니며, 실제 케어 기록→형태 분기 로직은 미정이다.

**화면/캐릭터:** 휴대폰 전체가 방이다. 펫은 작고 바닥은 넓으며, 러그 밖 빈 바닥도 이동한다. 크림색 모찌 같은 몸, 작은 뿔, 시크한 기본 눈매, 말캉한 쓰다듬기, 빠르고 부드러운 이동을 현재 기준으로 한다.

**개발:** 실제 앱 개발은 Codex에서 시작한다. 첫 작업 APP-01은 최신 GLB/모션/바닥 터치를 설치형 모바일 개발 빌드에서 재현하는 기술 스파이크다. 기존 HTML을 WebView로 포장해 완료 처리하지 않는다. 실제 건강정보/로그인/결제/서버는 이 단계에서 연결하지 않는다.

**플랫폼:** 모바일은 본게임. PC·위젯·Android 배경화면은 별도 확장이다. 여러 표면을 켠 시간으로 보상/성장이 중복되지 않는다.

**남은 결정:** 운영 스택/지원 OS, 수면 점수, 진화 분기/2차 아트, 가격·성장 밸런스, 법정 동의, 동기화·출시 정책.
