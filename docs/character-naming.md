# 아루콘 — 캐릭터 명명 규칙 v1.7

작성일: 2026-09-18  
상태: **제품 명명 범위 승인 / 분기 로직·2차 아트 OPEN**  
근거: SRS FR-5/10/16, DEC-08, DEC-18, **DEC-32**

## 1. 이름의 세 층을 섞지 않는다

| 층 | 예시 | 의미 |
|---|---|---|
| 서비스/계보 | `Arucon`, 내부 `speciesFamily=arucon` | 프로젝트·세계관 계보 식별. 진화형의 사용자-facing 이름을 대신하지 않음 |
| 개체명 | `구름콘` | 사용자가 정한 `givenName` + 고정 접미사 `콘`. 진화해도 유지 |
| 진화형 대명사 | `아루콘`, `말루`, `모노`, `피코`, `몽글` | 현재 외형 형태를 부르는 이름. 성격 프로필과 별도 |

UI에서 “구름콘이 말루로 진화했어요”처럼 쓴다. `말루콘`으로 개체명을 다시 만들거나, 진화 후 사용자가 지은 이름을 형태명으로 덮어쓰지 않는다.

## 2. 승인된 형태 카탈로그

| formId | 한국어 표시 | 로마자 작업 표기 | 외형 키 | 성격 연결 |
|---|---|---|---|---|
| `arucon` | **아루콘** | Arucon | 공통 아기형. 작은 뿔, 짧고 처진 귀, 낮고 말캉한 몸 | 없음 |
| `mallu` | **말루** | Mallu | 더 낮고 넓게 퍼지는 몸, 양옆으로 늘어진 귀 | 없음 |
| `mono` | **모노** | Mono | 세로로 조금 더 선 몸, 비대칭 귀, 정돈된 실루엣 | 없음 |
| `piko` | **피코** | Piko | 두 귀가 위로 선 뾰족한 실루엣 | 없음 |
| `mongle` | **몽글** | Mongle | 둥근 귀, 말린 꼬리, 구름처럼 둥근 실루엣 | 없음 |

이름은 현재 승인된 **개발/제품 표시명**이다. 로마자 표기와 상표 사용 가능성은 출시 전에 DEC-18에서 별도 확인한다.

## 3. 왜 기존 가칭을 바꿨는가

기존 `말랑형/시크형/쫑긋형/몽실형`은 디자인 토론용 라벨이었다. 특히 `시크형`은 외형과 성격을 섞어 읽힐 위험이 있어 형태명에서 제거한다. `모노`는 **세로형·비대칭·간결한 실루엣**을 가리킬 뿐, 반쯤 감긴 눈이나 츤데레 행동을 강제하지 않는다.

아루콘의 성격은 `personalityProfileId`로 따로 표현한다. 예를 들어 말루도 조용할 수 있고, 모노도 먼저 다가오는 성격일 수 있으며, 피코나 몽글도 츤데레일 수 있다.

## 4. 코드/데이터 규칙

```text
Pet
- speciesFamily: "arucon"        # 내부 계보. 표시명과 동일 개념 아님
- givenName: "구름"               # 사용자 입력 본문
- formId: "arucon|mallu|mono|piko|mongle"
- personalityProfileId: 별도 키

표시
- petDisplayName = givenName + "콘"
- formDisplayName = CharacterFormCatalog[formId].displayName
```

`CharacterFormCatalog`은 사용할 수 있지만 `AppearanceResolver`는 DEC-08이 승인되기 전 실제 케어 기록으로 형태를 확정하면 안 된다. 테스트/아트 프리뷰에서 formId를 직접 주입하는 것은 가능하다.

## 5. 아직 이름을 만들지 않는 범위

2차 성체화 및 이후 세부 파생은 외형 자체가 아직 충분히 정의되지 않았다. Codex가 `말루2`, `슈퍼피코`, `성체모노` 같은 이름을 임의 생성하지 않는다. 새 외형 시트가 정해지면 **각 실제 진화 캐릭터마다 같은 방식으로 고유 대명사**를 붙이고 DEC에 승인 기록을 추가한다.

## 6. 수용 기준

`AT-APPEARANCE-04~07`을 따른다. 핵심은 **개체명 보존, 형태명 분리, 성격 비강제, 명명 승인과 분기 승인 분리**다.


## v1.8 운영 메모

ENG-03 멀티모델 자율 개발은 이 명명 규칙을 바꾸지 않는다. 어떤 역할도 2차 형태 이름이나 실제 케어→형태 분기 규칙을 임의 생성하지 않는다.
