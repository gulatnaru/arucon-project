# APP-01 기술 검증 기록

## 구현 경계

- FR-10.1/16과 DEC-27의 승인 방향: 전체 화면 방, 작은 아루콘, 넓은 바닥, 분리된 터치, 원본 GLB 모션.
- DEC-12/31은 OPEN이다. Expo SDK 57 + Three.js는 설치형 스파이크 후보이며 운영 채택/지원 OS 결정이 아니다.
- 에셋 복사 전후 SHA-256이 동일하다. 원본이나 morph/animation 데이터는 편집하지 않았다.
- 원래 웹의 모든 가구 미세 형상/셰이더를 이식한 결과는 아니다. 승인 GLB는 그대로이고 방의 주요 색/배치만 네이티브 메시로 재현했다. 시각 동등성은 네이티브 캡처가 필요하다.
- 네이티브에서는 GLB 클립을 Three.js AnimationMixer로 재생하고 루트에 스프링 눌림을 얹는다. 기존 웹의 부위별 morph 수동 보간과 직접 조작 중 표정 세부값은 그대로 포팅하지 않았다. 손맛/표정 동등성은 실제 화면 녹화에서 비교해야 한다.
- `mealCue`는 상위 서비스가 확정한 섭취를 화면에 표현하는 신호다. 장면은 1회 `eat` 클립을 1.2배로 재생하되 먹이/EXP/체력을 바꾸지 않는다. 공 hit는 기존 성격별 ball clip을 1회 재생한다.
- 움직임 줄이기에서는 터치/식사/공 클립의 0.25초 이하 고정 포즈를 0.45초만 보여주고 idle로 돌아간다. 스프링을 적분해도 표시에는 반영하지 않는다. 수동 목적지 이동과 경제 콜백은 계속 작동한다.

## 검증 상태

- `node --import tsx --test tests/scene/*.test.ts`: 앞/뒤/좌/우 러그 밖, 가장자리, 식탁/화장실 설치 상태, 경로 전환, 비정상 좌표, 늦은 GLB 로드 정리, RAF 단일 예약, 움직임 줄이기 직접 반응, 성격별 이동 수치, 교감 스프링을 검사한다.
- `npm run typecheck`, `npm run lint`, `npx expo export`와 네이티브 빌드는 실행 로그와 함께 최종 보고한다.
- GLView/GLTFLoader가 실제 iOS/Android 기기에서 원본 GLB morph와 15개 애니메이션을 렌더하는지, 프레임/메모리, 펫 얼굴과 접촉/가구 회피를 실제 화면으로 확인해야 한다. 코드/번들만으로 APP-01 PASS를 선언하지 않는다.

## 미리 확인된 환경 제약

이 개발 호스트는 Node.js 26.7.0과 Xcode Command Line Tools만 확인됐다. `xcodebuild -version`은 전체 Xcode가 없어 실패했다. `adb`/`emulator` 명령도 발견되지 않았다. 네이티브 실행/캡처를 못하면 `확인 불가`로 분리한다. 전역 SDK 설치나 계정 생성은 실행하지 않았다.
