# Arucon widget pet asset

Prompt: “Extract top-left approved front portrait only; preserve shape/face/half-closed eyes/cream colors/ears/horn/feet; remove sheet text; square warm off-white; no redesign.”

The asset is presentation-only. It does not add Health, account, payment, store, or widget command behavior.
