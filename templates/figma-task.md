# Figma 반영 작업 브리핑

이 템플릿의 존재만으로 원격 쓰기를 승인하지 않는다. 사용자의 현재 Figma 반영 요청에 연결해 사용한다.

명시 호출: $arucon-figma-handoff
승인된 계정 식별 / 팀:
지정된 파일 URL·fileKey / 대상 페이지·노드:
반영할 화면·문구·상호작용 / 원본 자료 경로:
허용 행위: 지정 범위의 생성 또는 수정
보호: 다른 계정·파일·사용자 기존 작업·공유 설정
완료 조건: 실제 편집 ID 확보, 하위 노드 재조회, 화면별 렌더 확인, 범위 차이 보고
중단: 계정 불일치·편집권한 거부·상한·통신 실패·범위 밖 삭제/공유
보고: 접근/대상/쓰기/재조회/시각검증을 분리

시각 자료가 래스터 캡처라면 텍스트·캐릭터·가구가 각각 편집 가능하다고 하지 않는다.
실행형 게임·3D/Rive 파일·네이티브 앱 이식은 별도 배정이다.
