# 총괄 작업 템플릿

아루콘 저장소의 현재 사용자 변경을 보존하면서 아래 결과를 구현하라.
관련 지침·FR/DEC·코드·검사만 읽고, 승인된 로컬 작업은 구현→검증→관련 실패 수정까지 이어가라.
작은 작업은 직접 수행한다. 독립된 탐색/검토에서 이점이 있을 때만 서브에이전트를 사용하고 실제 사용 여부를 보고하라.
자식에게는 task-brief.md의 결과·제약·검증·멈출 지점과 파일 소유 범위를 전달하라.
읽기 역할은 외부 쓰기·제품 코드 변경을 하지 않는다. 동일 파일의 동시 작성자는 하나다.
결과를 통합한 뒤 기능과 실제 시각 증거를 대조한다. 사용자 승인·기기 성능·원격 배포와 코드 테스트를 구분하라.
전역 설정을 변경하거나 모델을 임의 교체하지 마라. 범위 밖 제품 결정·계정·공유·배포는 해당 부분만 보류하라.
